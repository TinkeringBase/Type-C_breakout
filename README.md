# FTIndustries Type C breakout
![preview](https://github.com/FTIndustries/Type-C_breakout/blob/main/3dpreview.png?raw=true)\
ESD-Safe USB Type C power breakout that act as upstream-facing port, UFP, aka "peripheral device" and draws 5V from host device. It can draw current up to 3A. It can be held in place with two M2 bolts. It can transfer USB 2.0 data. It has 3-channel TVS so it is safe from ESD.
## pinout
VB - VBUS\
DP - Data Positive\
DN - Data Negative\
G - Ground
